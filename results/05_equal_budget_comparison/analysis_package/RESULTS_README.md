## 结论适用范围

六实例平均HV与平均经验IGD均支持QDMOPSO在本次协议下的竞争力，但不能称经多重校正后显著优于每个基线。相对MOPSO的平均HV优势随实例变化：S1约2.69%、M2约1.97%、L3约0.90%、G100约1.66%、G200约0.38%、G300约0.12%；这些是HV相对变化，不是工期或成本降幅。G300平均测试含记录时间Q约463.55秒、MOPSO约249.85秒，不能声称Q更快或同NFE等于同时间，更不能忽略Q训练费用。记录仪器化开销与不同时段机器负载保留，速度差不能全部归因算法。
