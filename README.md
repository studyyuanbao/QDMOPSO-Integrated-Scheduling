Private review candidate for the Engineering Optimization revision. This repository holds code snapshots, inputs, protocols, selected results, and validation records. A file's presence does not prove that every historical figure has been reproduced. No experiments were run to prepare this repository.

## Scope and use

The scripts are archival snapshots. Some still assume their former working directory or depend on optional Gurobi, Python libraries, and licensed solver access. `requirements.txt` lists observed dependencies; a clean environment has not been tested. The two original reconstruction runners in the hold list modify working copies or package archives and were not made portable by a path substitution. The portable validation checker reads the included schedule snapshot and writes a separate recheck file if run; the recorded validation result remains untouched.

Large source archives remain outside this repository and are indexed in `docs/large_data_manifest.csv`; no external download URL is claimed. Historical nine-instance HV/IGD reference construction and fixed-strategy Q-table provenance are unresolved. The ablation study cannot establish module contributions under the final revised model without further validation. No license is granted here, and this private candidate is not yet a public reproduction release.
